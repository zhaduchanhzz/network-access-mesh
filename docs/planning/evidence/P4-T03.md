## 2. Màn hình và API

| Màn hình (đường dẫn trên `admin.`) | API | Ghi chú |
|---|---|---|
| Instances `/platform/instances` | `GET /platform/instances?limit=25&status=&host=&cursor=` | Lọc trạng thái (7 giá trị của spec), lọc host qua `?host=` (từ trang host); bảng: hostname → chi tiết, trạng thái, health (badge + lý do đã dịch + `checked_at`), version, tenant, host |
| Instance detail `/platform/instances/:id` | `GET /platform/instances/{id}`, `GET /platform/instances/{id}/config-versions` (**mới**), `GET /platform/backups?instance=&status=succeeded` | Version Headscale, image digest, health có `checked_at`, server URL, network, UID, DERP region, hạn API key, fingerprint Noise key; version cấu hình (mới nhất trước, `current` đánh dấu `aria-current`, trạng thái, template, SHA-256, tạo/áp dụng) + tham số render của version hiện hành; instance được adopt (chưa có version do orchestrator ghi) ⇒ nói rõ reconfigure/upgrade sẽ bị 409. Backup gần đây chỉ khi role có `platform.backup:read`. id không phải UUID ⇒ 404 không gọi API |
| Thao tác instance | `POST …/restart`, `…/backup` (không body), `…/reconfigure` (`InstanceReconfigure`), `…/upgrade` (`InstanceUpgrade`), `…/quarantine` (`{reason}`) ⇒ 202 + `Location` job ⇒ timeline có sẵn; `…/restore` (`InstanceRestoreCreate`), `…/release` (`{reason}`) ⇒ 202 + `Location` approval ⇒ trang phê duyệt có sẵn (người yêu cầu thấy "đã gửi", không có nút duyệt) | Mọi lệnh `Idempotency-Key` (một khóa cho một ý định — lỗi mạng ⇒ gửi lại cùng khóa). Nút theo quyền (`:operate`, `:upgrade`, `:restore`, `:quarantine`, `:release`) + trạng thái (restart/reconfigure/upgrade khi `running`, release khi `quarantined`…; server quyết định 409). Reconfigure: chỉ gửi trường đã điền, miền giá trị của spec; upgrade: digest `sha256:<hex64>`, khác digest đang chạy; restore: chọn bản backup thành công, cờ "PostgreSQL cũ hơn bản backup", lý do; quarantine: gõ lại hostname + lý do |
| Hosts `/platform/hosts`, `/platform/hosts/:id` | `GET /platform/hosts`, `GET /platform/hosts/{id}`, `GET /platform/instances?host=` | Capacity `n / max` (max 0 ⇒ "không nhận mới"), **cổng STUN còn trống** (`usage.stun_ports_free` — **mới**; `null` ⇒ "STUN chung"), slot /29, UID còn cấp được, dải UID/STUN/pool, điểm vào công khai + chế độ, heartbeat gần nhất, instance theo trạng thái, danh sách instance trên host. Chỉ đọc (ghi host vẫn qua lệnh host / PATCH của P3-T04) |
| Platform Health `/platform/health` | `GET /platform/health` (làm mới 30 s) | Tenant (tổng + theo trạng thái), instance (tổng, số lỗi health, theo trạng thái/health/version), job (chưa kết thúc theo trạng thái, lỗi/lùi 24 giờ, `checked_at` riêng), thành phần: có số đo ⇒ health + lý do + `checked_at`; `unknown` ⇒ khối "không khả dụng" kèm lý do đã dịch + mã (`no_probe`, `not_deployed`, `no_heartbeat`…). API lỗi ⇒ thông báo + thử lại, không số nào |
| Relay Regions `/platform/relay-regions` | `GET /platform/relay-regions` | Chỉ đọc (ghi thuộc P7-T04): region, loại, điểm vào, trạng thái quản trị, health + `checked_at`, tenant sở hữu / "dùng chung", instance được gán; `unavailable[]` ⇒ "không khả dụng" kèm lý do |
| Thiết lập `/platform/settings` | `GET /platform/settings`, `PUT /platform/settings/{key}` (`If-Match` = `etag` của bản đã đọc) | Tập khóa đóng; mô tả theo khóa (i18n, dự phòng mô tả của server); `maintenance` "chỉ đọc (lệnh host)"; nút sửa chỉ khi `platform.settings:update` (SA). | Nhân sự nền tảng `/platform/users` | `GET /platform/users`; `POST` (Idempotency-Key), `PATCH`/`DELETE` (`If-Match`), `PUT /platform/users/{id}/super-admin-role` | Lọc trạng thái/role; hàng của chính mình đánh dấu "(bạn)" và không có thao tác; hàng SA chỉ có "gỡ SA" (điều kiện `excludes_super_admin`); role chọn được chỉ dưới SA; gán/gỡ SA ⇒ hộp nêu 2P + lý do ⇒ 202 ⇒ trang phê duyệt.
