## Thiết kế đã dựng

| Thuộc tính | Giá trị |
|---|---|
| Interface | `mg-wg0` (kernel WireGuard, `wg-quick@mg-wg0` do systemd quản lý, bật lúc boot ở cả hai đầu) |
| Địa chỉ | `10.248.0.0/30` — VPS `10.248.0.1/32`, host LAN `10.248.0.2/32` (không chồng LAN, pool Docker, pool tenant/platform, `100.64.0.0/10`) |
| Khóa | Sinh **tại từng máy** (`/etc/wireguard/mg-wg0.key`, 0600); file cấu hình không chứa khóa riêng (nạp bằng `PostUp = wg set %i private-key …`); chỉ public key được trao đổi |
| Kết nối | VPS lắng nghe UDP 51820; **host LAN chủ động kết nối** (`PersistentKeepalive = 25`) ⇒ không cần port forwarding ở LAN; `AllowedIPs` mỗi đầu chỉ là /32 của đầu kia |
| Firewall host LAN | `forward`: chỉ `10.248.0.1` → `10.249.0.2` TCP 8080/8443 (listener tunnel-facing của edge, sau DNAT) — mọi kết nối mới khác từ `mg-wg0` bị chặn; `input`: chỉ ICMP echo từ `10.248.0.1`. Áp có hẹn giờ tự hoàn tác (bản trước: `/etc/meshguard/host-firewall.nft.before-p1-t16`) |
| Thứ tự khởi động | Drop-in `docker.service.d/10-meshguard-wg.conf`: `After=`/`Wants=wg-quick@mg-wg0` — edge publish cổng trên IP tunnel nên interface phải có trước khi Docker start container (interface được tạo kể cả khi VPS không trả lời) |

## Kiểm chứng

| # | Phép thử | Kết quả |
|---|---|---|
| 1 | Handshake | VPS thấy đầu host tới từ IP công khai của LAN `118.68.116.x` (cổng do NAT cấp); handshake đều đặn |
| 2 | Ping qua tunnel | host → VPS: 3/3, RTT ~22 ms; VPS → host: 2/2, RTT ~22–27 ms |
| 3 | Từ VPS chỉ tới được hai cổng tunnel-facing của edge | `10.248.0.2`: 22, 80, 443, 5432, 8081 ⇒ đóng/lọc; 8080, 8443 ⇒ mở **sau khi** edge publish ([P1-T17](P1-T17.md)) — **đạt** |
| 4 | Tự nối lại | Diễn tập dựng lại gateway (gỡ/dựng lại container trên VPS) không cần thao tác tay với tunnel ([P1-T18](P1-T18.md)). **Chưa thử** reboot host hay VPS **sau khi** có tunnel (lần reboot của [P1-T21](P1-T21.md) diễn ra trước P1-T16) — thứ tự khởi động Docker sau tunnel mới chỉ đúng theo thiết kế, cần kiểm ở lần reboot kế tiếp |

Hoàn tác (mỗi đầu): `sudo systemctl disable --now wg-quick@mg-wg0 && sudo rm /etc/wireguard/mg-wg0.{conf,key,pub}`; host: gỡ drop-in Docker và áp lại firewall bản trước.
