## 2. Định tuyến (`app.<domain>`, `admin.<domain>`)

Thứ tự tường minh trong `route` (không phụ thuộc cách Caddy sắp `handle`):

| # | `app.` (LAN-direct + tunnel-facing) | `admin.` (chỉ LAN-direct, chỉ `admin_allow`) |
|---|---|---|
| 1 | `abort @direct_tunnel` (chỉ listener tunnel-facing) | `abort @from_tenant_pool`, `abort @outside_admin` |
| 2 | `abort @from_tenant_pool` | `respond @unsafe_path 404` (`\`) |
| 3 | `respond @unsafe_path 404` | `route @idp_console { forward_auth api /internal/edge/idp-console → impersonation 403 → idp }` — **giữ nguyên P3-T15** |
| 4 | `respond @dot_segment 404` **(mới)** | `respond @dot_segment 404` **(mới)** |
| 5 | `reverse_proxy /api/* api.:8080` (như cũ, `upstream_headers`) | `reverse_proxy /api/* api.:8080` |
| 6 | `reverse_proxy web.:8080` **(mới — thay `respond 404`)** | `reverse_proxy web.:8080` **(mới)** |

- **`@dot_segment`** = `vars_regexp dot {http.request.uri.path} (^|/)\.` — path **thô** (đã giải mã `%xx`, chưa làm sạch) có đoạn bắt đầu bằng `.`: dotfile, `/./`, `/../`, kể cả `%2e%2e` và `..%2f`. Lý do: matcher `path` của Caddy so path **đã làm sạch**, nên `/api/../metrics` thành `/metrics`, không khớp `/api/*` và — nếu không chặn — rơi sang SPA (200) thay vì 404. `auth.` không dùng matcher này (Keycloak cần `/.well-known/…`); console Keycloak trên `admin.` được xử lý ở bước 3, trước bước 4.
- `/internal/*` (cổng `forward_auth`, SD Prometheus), `/healthz`, `/readyz`, `/metrics` của api: nay là `index.html` của SPA — **không bao giờ tới api** (conformance kiểm body = `index.html`). `/api` (không gạch chéo) ⇒ container web trả 404.
- **Trang lỗi**: `handle_errors 502 503 504` của snippet `portal_site` ⇒ `503 "Service temporarily unavailable"`, `Retry-After: 30`, `Cache-Control: no-store` — khi web/api/console không trả lời (container dừng, đang deploy). Trước đây api dừng ⇒ 502 rỗng mặc định của Caddy.
- Network: service `web` chỉ ở `mg-edge` (alias = tên service, upstream rooted `web.` như `api.` — edge có `dns_search: ["."]`), không IP tĩnh (như api: edge không cần phân biệt nguồn), không DB, không `mg-egress`. Không mở network mới: `mg-edge` là network edge vốn đã dùng để tới api. Ghi nhận: `mg-edge` không `internal` (edge publish cổng qua nó) nên container web về lý thuyết có đường ra ngoài qua gateway của bridge — container chỉ là Caddy phục vụ file tĩnh, không secret, không cấu hình proxy; chấp nhận (cùng mức với api trước khi có `gw_priority`).

## 3. Header bảo mật — một nguồn: edge

| Phương án | Đánh giá |
|---|---|
| Cả edge và container đặt (P4-T01) | Hai chỗ phải giữ giống nhau (test so khớp ký tự); header `defer` của edge ghi đè nên trình duyệt chỉ thấy một giá trị, nhưng mọi thay đổi phải sửa hai nơi và rebuild image |
| Chỉ container web | Không phủ phản hồi của api (`/api/*`), trang lỗi và 404 do edge tự trả — vẫn phải giữ ở edge ⇒ lại hai nguồn |
| **Chỉ edge (chọn)** | Một chỗ cho **mọi** phản hồi của hai origin: api, SPA, 404 của edge, trang 503. Container chỉ ở `mg-edge`, không bao giờ được phục vụ trực tiếp cho trình duyệt |

- `(platform_headers)`: HSTS, `nosniff`, bỏ `Server` — mọi site nền tảng (cả `auth.`).
- `(portal_headers)` (`app.` mọi phản hồi; `admin.` trừ console Keycloak): CSP `default-src 'self'; base-uri 'none'; object-src 'none'; frame-ancestors 'none'; form-action 'self'`, `X-Frame-Options DENY`, `Referrer-Policy no-referrer` và — **chuyển từ container** — `Cross-Origin-Opener-Policy same-origin`, `Cross-Origin-Resource-Policy same-origin`, `Permissions-Policy camera=(), microphone=(), geolocation=(), payment=(), usb=()`. Thêm ba header này vào phản hồi JSON của api là vô hại (cùng origin).
- `handle_errors` chạy ngoài route chính nên header `defer` của site không áp dụng cho trang lỗi ⇒ `portal_site` import lại `platform_headers` + `portal_headers *` (vẫn một định nghĩa).
- Container web (`infrastructure/docker/web/Caddyfile`): chỉ `Cache-Control` (theo nội dung) và bỏ `Server`; `@hidden` chuyển sang path thô (cùng lý do với `@dot_segment`). Khóa bằng: `apps/web/src/security/csp.test.ts` (đúng một CSP trong template edge, không CSP/HSTS/… nào trong Caddyfile container, trang lỗi import header), `test_render_edge.py` (`Content-Security-Policy` xuất hiện đúng một lần), khối kiểm `web)` của `images.yml` (container phát header bảo mật ⇒ fail), E2E-85 (mỗi header đúng **một** giá trị trên SPA lẫn api).
- Image web có thêm `/usr/bin/healthprobe` (cùng mã `infrastructure/docker/edge/healthprobe`, chỉ thư viện chuẩn) cho healthcheck của compose (distroless không có curl).
