## Số đo

| Phép đo | N = 100 | N = 300 |
|---|---|---|
| Tạo network + container giả | 35 s (100) | 82 s (thêm 200) |
| `docker network connect` edge — mỗi lần | p50 68 ms, p95 77 ms, max 92 ms (tổng 6,9 s) | p50 100 ms, p95 117 ms, max 133 ms (200 lần, tổng 20,2 s) |
| Stream của client (8) bị đóng khi gắn | **0** (4-tuple trùng) | **0** |
| Phân giải `hs-<slug>.` trong netns của edge (đầu, giữa, cuối dãy; tenant thật; tên không tồn tại) | < 1 ms (dig báo 0 ms, 5 lần mỗi tên) | < 1 ms |
| **Restart edge** (`docker restart`; Docker giữ network gắn lúc chạy) | trả về 8,8 s + healthy 2,1 s ⇒ **11,0 s** tới khi `tenant-a /key` = 200; 106 network giữ nguyên | trả về 30,8 s + healthy 2,2 s ⇒ **33,1 s**; 306 network giữ nguyên |
| **Recreate edge** (`compose up --force-recreate`; mất network gắn lúc chạy) | 5,9 s + healthy 2,1 s; gắn lại A/B (`reattach-edge.sh`) + 100 network: 7,8 s ⇒ **15,9 s** tới khi gắn đủ | 15,2 s + 2,1 s; gắn lại 302 network: 30,2 s ⇒ **47,6 s** |
| `docker network disconnect` — mỗi lần (dọn dẹp) | — | p50 99 ms, p95 120 ms (300 lần, tổng 30,3 s) |
| RAM edge (nhàn rỗi) | 19,4 MiB | 15,0 MiB (sau restart) |
| RAM Headscale tenant A (2 node, nhàn rỗi) | 14,2 MiB; CPU ~0,1% | 14,0 MiB |

Restart và recreate đóng mọi stream của mọi tenant (đúng thiết kế — §14.6, §17.4); client tự kết nối lại (sau phép thử: a2 → a1 `direct`, b2 → b1 `DERP(mg-tenant-b)`, probe A/B `key=200 derp=200`).

## Đối chiếu ngưỡng G0

Ngưỡng ([G0.md](G0.md)): **restart edge < 60 s khi có 100 network tenant** ⇒ đo được **11,0 s — đạt** (300 network: 33,1 s). Không cần xem lại ADR-08 trước G1.

## Nhận xét

- Thời gian restart/recreate edge tăng gần **tuyến tính theo số network** (~0,1 s mỗi network cho cả gắn, gỡ và restart): đây là yếu tố giới hạn số tenant trên một host chứ không phải RAM của instance hay độ trễ phân giải tên.
- **`hosts.capacity` tạm tính: 100 instance/host** (restart edge ~11 s, recreate + gắn lại ~16 s). Lên 300 vẫn dưới 60 s nhưng thời gian rớt toàn bộ stream khi recreate (~48 s) dài hơn đáng kể ⇒ quyết định trần lớn hơn ở P6-T08 với số node thật mỗi tenant (RSS nhàn rỗi 14 MiB/instance là chưa có tải — §5.5).
- Recreate edge làm mất network gắn lúc chạy ⇒ `reattach-edge.sh` là bước bắt buộc của mọi lần recreate ở Phase 1–2 (§17.6); từ Phase 3, Agent reconcile tự gắn lại.
