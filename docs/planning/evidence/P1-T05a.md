## Các bước

1. Instance `spike` theo thứ tự §11.3: thư mục → network `mg-t-spike` (`internal`, `10.250.255.248/29`) → start (healthy sau ~6 s) → policy deny-all qua CLI, đọc lại khớp → gắn edge (`docker network connect`, **không reload Caddy**) → network có đúng 2 thành viên (`mg-hs-spike`, `mg-edge`) → áp fixture `test-allow-intra.hujson`.
2. Client: `TS_DEBUG_ALWAYS_USE_DERP=true` trong `/etc/default/tailscaled` (CL-10) — `ss -lunp` cho thấy `tailscaled` không mở socket UDP nào.
3. Đăng ký: mỗi client một pre-auth key **dùng một lần, hạn 1 giờ** (`headscale preauthkeys create --user 1 --expiration 1h`), chuyển thẳng từ host sang client qua pipe (`--auth-key=file:/dev/stdin`) — key không xuất hiện trong lệnh, log hay tài liệu.
