Đã sửa bằng guard `@direct_tunnel` (template_version 4) — [P1-T18](P1-T18.md#phát-hiện-listener-tunnel-facing-phục-vụ-kết-nối-không-có-proxy-header-từ-nguồn-khác). `caddy adapt` xác nhận: server `10.249.0.2:8443` có `[proxy_protocol, tls]`, `REQUIRE`, `strict_sni_host`; server `10.249.0.2:8080` có `[proxy_protocol]`, `REQUIRE`.
