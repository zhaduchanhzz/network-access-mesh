Đề xuất cho master khi hợp nhất: §14.4 hàng "api, worker" ghi "compose project riêng `mg-app`"; §14.3 thêm `worker` vào `mg-edge` (IP tĩnh `10.249.0.4`, chỉ để edge nhận diện nguồn Admin API của IdP — P2-T05a); §14.2 bảng nhóm: `mg-sec-migrate` giữ thêm **bản** mật khẩu 6 role đăng nhập (job migrate đặt chúng — `mg_migrator` vốn có ADMIN trên các role đó nên bản sao không mở rộng quyền), `mg-sec-app` chưa gắn vào worker cho `mg_audit_writer`.
